# 💡 Bulb ON & OFF Project

This is a simple **Bulb ON and OFF** web project built using **HTML, CSS, and JavaScript**.  
Users can turn the bulb ON or OFF by clicking buttons.

---

## 🚀 Features
- Bulb ON button
- Bulb OFF button
- Image change on button click
- Beginner-friendly JavaScript logic
- Clean and simple UI

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
